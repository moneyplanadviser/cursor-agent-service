プライバシーポリシー

制定日：2026年10月1日 ／ 運営：SHIRO（青木翼）

SHIRO（以下「当方」）は、当サイトおよび当方が運営するサービス・社内ツールにおける個人情報と利用者データの取り扱いについて、次のとおり定めます。

1. 取得する情報

  • お問い合わせ・お申し込み・ヒアリングフォームで入力いただいた、お名前・メールアドレス・ご相談内容。
  • お支払いの手続きに必要な情報（決済はStripe等の決済事業者が処理し、カード番号は当方では保持しません）。
  • サイトの利用状況（アクセス元・閲覧ページ等。Cookieを含む場合があります）。

2. 利用目的

  • ご相談・ご契約への対応、サービスの提供、ご連絡のため。
  • 料金のご請求・お支払いの確認のため。
  • サービスの改善と、不正利用の防止のため。

3. 第三者への提供

法令に基づく場合を除き、ご本人の同意なく個人情報を第三者へ提供しません。決済・メール配信・ホスティング等の業務を委託する場合は、必要な範囲に限り、適切に管理します。

4. Google・YouTube API サービスの利用について

当方は、自社の動画をYouTubeへアップロードする社内用ツールで YouTube Data API を使用します。

  • 使用する権限：動画のアップロード（youtube.upload）のみ。
  • 対象：当方が運営するチャンネルの動画のみ。第三者のアカウント・データにはアクセスしません。
  • 認証情報（トークン）は、運営者本人の端末内にのみ保存します。外部へ送信・共有・販売しません。
  • Google ユーザーデータの利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。
  • Google アカウント側の「セキュリティ」→「サードパーティのアクセス」から、いつでもアクセス権を取り消せます。

5. 安全管理

取得した情報は、不正アクセス・紛失・漏えいを防ぐため、アクセス権限の管理など合理的な安全対策を講じます。

6. 開示・訂正・削除のご請求

ご自身の情報の開示・訂正・削除をご希望の場合は、下記の窓口へご連絡ください。ご本人確認のうえ、合理的な期間内に対応します。

7. 改定

本ポリシーは、必要に応じて改定します。改定後の内容は、このページに掲載した時点で効力を生じます。
